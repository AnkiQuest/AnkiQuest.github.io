AnkiQuest wiring

How every AnkiQuest repository, upstream and package feeds the others: submodules, Maven and Cargo dependencies, Nix flake inputs, reusable workflows, pinned AnkiQuest-Server data, AGENTS.md from AnkiQuest-Agents, upstream merges and watched sources. Arrows point the way code or data flows. Regenerated daily from the repositories' default branches.

Lanes group the repositories by role, in the order code flows: upstreams, core, clients and app forks, server and web, with shared infrastructure along the bottom. On a phone the upstreams stay on the left and the other lanes stack on the right. Flake inputs, reusable workflows, CI checkouts, vendored code and AGENTS.md start hidden and show as badges on each repository, such as “Dev: flake !, 4 workflows”. Hover over, click or tap a node or line to focus on it and its neighbours; Escape or a click on empty space clears the focus.

Legend

  • Each edge kind has its own colour and line style, shown next to its checkbox above.
  • One line per pair of nodes: it holds every kind of link between them (a Cargo pin and a watched source at the same commit are one line), shows when any of its kinds is ticked and takes the colour of the first one ticked. Its details and the table list each kind with its own pin and file.
  • ! out of date: thick line marked “!” with the commits behind, one number when its kinds agree, else each (“! 14, 3”); a node with an out-of-date line into it gets a thick border and a “!” before its name; in a badge, “!” after the item.
  • ? unknown: not readable. ~ planned: decided, not made yet (faint line, dashed node).
  • AnkiQuest repository; fork (double border); upstream or other source; package; faded: no line shown for the current filters.
  • Badges below a repository's name list the hidden kinds: “Dev: flake !, 4 workflows” is a flake input and four reusable workflows from AnkiQuest-Dev, the flake input out of date; “AGENTS.md → 13 (12 !)” is a file sent to 13 repositories, 12 of them out of date.
